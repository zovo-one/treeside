Privacy Policy · TreeSide

Last updated: 2026-07-21

Summary

TreeSide is a tree-style vertical-tabs side panel for Chrome. It reads only the tab metadata Chrome already maintains (title, URL, opener relationship, group membership) to draw and manipulate the tree. It never reads page content, never injects scripts into pages, and never makes a network request except when you explicitly enter a license key. All settings, overrides, and collapse state stay on this device in Chrome extension storage.

Permissions and why each one is required

  • tabs. Reads tab metadata (title, URL, openerTabId, groupId, active state, audible state). Used to build and update the tree. The permission also allows the user-initiated actions (click-to-focus, middle-click-to-close, close-branch) to call chrome.tabs.update and chrome.tabs.remove. TreeSide never reads page DOM via this permission.
  • tabGroups. Reads and edits Chrome's native tab groups (color, name, membership). The group's color pip and name render in the tree; the user can rename/recolor via Chrome's native UI.
  • sidePanel. Opens the side panel surface — the entire product UI lives in Chrome's native Side Panel.
  • storage. Persists user preferences (theme, accent, row height, confirm threshold), Pro license state (only if you have Pro), the manual reparent overrides map, and the collapse set. storage.local only — never storage.sync.

What we never request

TreeSide never requests host_permissions, activeTab, scripting, webRequest, declarativeNetRequest, notifications, clipboardWrite, identity, <all_urls> (in matches), optional_host_permissions, history, cookies, or alarms.

What we read

TreeSide reads only the tab metadata that Chrome maintains: tab.id, tab.url, tab.title, tab.openerTabId, tab.groupId, tab.active, tab.audible, tab.pinned, tab.favIconUrl, and tab.windowId. It never reads the DOM of any web page. It has no content scripts. It cannot read your passwords, form data, browsing history, cookies, or page text.

What we store

  • storage.local.treeside_settings. Theme, accent, row height, confirm threshold, search weights.
  • storage.local.treeside_overrides. The manual reparent map (tabId → newParentId) so the tree survives Chrome restarts.
  • storage.local.treeside_collapse. The set of collapsed tab ids so collapsed branches stay collapsed across sessions.
  • storage.local.treeside_license. Pro license state (only if you have entered a license key).
  • storage.local.treeside_seen_onboarding. Boolean — has the user dismissed onboarding?
  • storage.local.treeside_funnel_events. A rolling 100-event log of product interactions (panel-opened, reparent, collapse, search, close-branch) kept only on this device for product-improvement purposes. No page content. No PII. Never sent anywhere.

What we transmit

Nothing, by default. The extension makes zero network requests during normal use. The only network request the extension ever makes is a POST to the Zovo license Edge Function when you enter a license key in Options. The request body is your license key and the extension's product ID. No page content, no browsing history, no tab URLs, and no profile data is ever sent. If you never enter a license key, the extension never opens a network connection.

Your choices

You can change theme, accent, row height, and confirm threshold from the Options page. You can export or delete all local data from the Data section of Options. Uninstalling the extension deletes all local data.
